Este proyecto realiza simulaciones de sistemas de colas en un banco para comparar el rendimiento de dos configuraciones de servicio de clientes.

Para mostar el informe debe: 

1) Otorgar permiso de ejecución al archivo *report_manager.sh*.
    ```bash
    $ chmod +x report_manager.sh
    ```
2) Ejecutar el script
    ```bash
    $ ./report_manager.sh
    ```
